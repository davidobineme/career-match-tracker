# CareerMatch Tracker

CareerMatch Tracker is a Python command-line application that helps users compare their resumes to job descriptions, save uploaded jobs and an opportunity to update the status of the jobs saved.

# Features

1. It adds job applications.
2. It saves the job applications to a JSON file.
3. It compares resume text against job descriptions and finds their similarities and differences.
4. It calculates a keyword match score in percentage.
5. It shows on the first 20 relevant missing keywords.
6. It views saved job applications.
